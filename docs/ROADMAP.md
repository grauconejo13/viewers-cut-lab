# Roadmap

The roadmap is phase-gated: each phase is implemented only after prerequisites
validate successfully.

| Milestone    | Outcome                                                            |
| ------------ | ------------------------------------------------------------------ |
| Phase 0      | Documentation and planning foundation                              |
| Phases 1-4   | Scaffold, UI, fictional concepts, ballots, and trusted totals      |
| Phases 5-8   | Gemini brief, creator approval, opening scene, continuity analysis |
| Phases 9-11  | Persistence, authentication/integrity hardening, orchestration     |
| Phase 12     | Agent Builder and confirmed partner MCP integration                |
| Phases 13-14 | Quality, accessibility, testing, deployment, and demo preparation  |

See [TASKS.md](../tasks/TASKS.md) for the authoritative sequence and acceptance
criteria. Scope remains limited to the lab MVP until an explicit decision expands it.
